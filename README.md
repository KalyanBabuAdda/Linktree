# Sriram LinkHub

Open `index.html` for the public page and `admin.html` for the admin app.

## Prototype features
- Public cinematic glassmorphism link page
- Add/edit/delete/show/hide links from admin
- Change display name, bio, tagline and background image
- Preview Site button
- Visit and per-link click counters
- Responsive mobile admin UI

This downloadable prototype stores configuration and analytics in the browser using localStorage, so it works without a server. For a real public deployment shared across visitors/devices, connect the same UI to a hosted database/auth backend (for example Supabase or Firebase) before using analytics as production data.
